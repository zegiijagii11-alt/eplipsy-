Google Drive синк ☁️

Google-ээр нэвтэрч холбоно. Дараа нь мэдээлэл өөрчлөгдөх бүрд Drive рүү автоматаар хадгалагдаж, шинэ утаснаас нэвтрэхэд бүгд сэргэнэ.

—
Доорх зааврын дагуу нэг удаа авна.
Авто-синк
Client ID хэрхэн авах вэ? (нэг удаа)
  1. console.cloud.google.com руу орж, Google-ээрээ нэвтэр.
  2. Дээд талаас шинэ төсөл (Project) үүсгэ — нэр: "Em Unalt".
  3. "APIs & Services → Library" → "Google Drive API"-г ол → Enable.
  4. "APIs & Services → OAuth consent screen" → External → өөрийн нэр/имэйл бөглө → Test users дотор өөрийн Gmail-ээ нэм.
  5. "APIs & Services → Credentials → Create credentials → OAuth client ID" → Application type: Web application.
  6. "Authorized JavaScript origins" дотор нэм: https://zegiijagii11-alt.github.io
  7. Create дарж гарсан Client ID-г хуулж, дээрх нүдэнд буулгана.
  8. Дараа нь "Google Drive-тэй холбох" дарж нэвтэрнэ.
Эм & Уналт — эпилепситэй хүнд зориулсан хувийн хянах дэвтэр. Нэвтэрсэн бол мэдээлэл тань таны бүртгэлд (Firebase) хадгалагдаж, нэвтэрсэн бүх утсан дээр синк болно. Зөвхөн та өөрөө харах эрхтэй.

Энэ апп нь эмчийн оношилгоо, эмчилгээ, зөвлөгөөг орлохгүй. Эм, тунгаа өөрчлөх, шинэ шинж тэмдэг илэрвэл заавал эмчтэйгээ зөвлөлдөөрэй. Яаралтай үед 103.

Энэ мэдээлэл яаралтай дэлгэцэнд (түгжээтэй үед ч) харагдана.
