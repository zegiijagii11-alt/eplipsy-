БАЙРШУУЛАХ (Netlify Drop):
1. Энэ zip-ийг задал (unzip).
2. Утас эсвэл компьютерын хөтчөөр app.netlify.com/drop руу ор.
3. Задалсан ХАВТАСАА (доторх файлуудтай нь) тэр хуудас руу чирж тавь.
   - Эсвэл энэ zip файлыг шууд чирж тавьж болно.
4. Хэдэн секундын дараа https://...netlify.app хаяг гарна.
5. Тэр хаягийг утсаараа нээ → Chrome ⋮ → "Нүүр дэлгэцэд нэмэх".

Файлууд:
- index.html               (апп)
- manifest.webmanifest     (апп тохиргоо)
- sw.js                    (офлайн ажиллах)
- icon-*.png, apple-touch-icon-180.png, favicon.png (дүрснүүд)
